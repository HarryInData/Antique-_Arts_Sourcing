# Antique Arts Sourcing — Official Web Application

**Antique Arts Sourcing** is a global manufacturer & exporter of handcrafted luxury decorative lighting, wire mesh pendant lamps, and bespoke architectural metalware for architects, interior designers, and luxury hospitality projects worldwide.

---

## 🚀 Live Production & Deployment

* **Live Domain**: [https://antiqueartssourcing.com](https://antiqueartssourcing.com)
* **Hosting Platform**: Hostinger JS Hosting
* **Automated CI/CD**: GitHub Actions auto-deployment on `push` to `main` branch ([.github/workflows/deploy.yml](.github/workflows/deploy.yml))

---

## 🛠 Tech Stack

* **Framework**: [Next.js 16 (App Router)](https://nextjs.org/)
* **Styling**: Tailwind CSS & Vanilla CSS Design Tokens
* **Animations**: Framer Motion & Canvas 3D Frame Rendering
* **SEO**: OpenGraph, Twitter Card, and JSON-LD (`Organization`, `WebSite`, `FAQPage`, `Product`, `BreadcrumbList`)

---

## 💻 Local Development

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
